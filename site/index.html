How it works

The LLM compiles, the runtime replays

Argus drives real Chrome (desktop, tablet, phone; several operators at once), injects changing conditions through the cockpit's own control API, and reads what the user sees — UI text by meaning, the video's decoded frame rate, the live Cesium map's real coordinates, layout geometry.

It then compares against independent ground truth from the simulator and backend. When the two disagree in a way that harms the user, that's a bug — proven, grouped by root cause, and recorded in a video whose HUD narrates the UI's claim next to the truth.
